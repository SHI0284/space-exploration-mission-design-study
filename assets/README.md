# Coastline data

`coastline.csv` is derived from Natural Earth 1:110m coastline (134 line features), downloaded 2026-11-03.

- Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_coastline.geojson
- Natural Earth data is public domain: https://www.naturalearthdata.com/about/terms-of-use/
- CSV columns are longitude/latitude degrees; NaN rows separate polylines.
- Visualization only; not used in numerical access calculations.
